# 수동 오토홀드: 트레일블레이저·트랙스 확장 (2026-11-12)

## 범위

트래버스 전용이던 수동 오토홀드(`docs/traverse_manual_hold_20261019.md`)를
2021-22 트레일블레이저(`CHEVROLET_TRAILBLAZER`)와 2024 트랙스(`CHEVROLET_TRAX`)에도 켠다.
동작 조건·기준값(페달 원시값 80, 1.5 m/s 미만에서 준비, 정차 시 마찰 브레이크 400, 가벼운 탭으로 해제)은 트래버스와 같다.

- 대상: 오픈파일럿 롱컨(알파 롱컨) 켜짐, 페달 인터셉터 없음, 순정 카메라 있음.
- 제외: `CHEVROLET_TRAILBLAZER_CC` 같은 크루즈 전용 차는 ACC 마찰 브레이크 경로가 없어 제외. 롱컨이 꺼져 있으면 동작하지 않는다.

## 바뀐 것

| 파일 | 내용 |
|---|---|
| `opendbc/car/gm/manual_auto_hold.py` | `MANUAL_HOLD_CARS`(차종 → SDGM 하네스 여부). 트래버스는 `HW_SDGM` 필수, 트레일블레이저·트랙스는 `HW_SDGM` 없어야 함. `NO_CAMERA`도 제외 조건에 추가 |
| `opendbc/car/gm/interface.py` | 롱컨 켜진 위 세 차종에 `MANUAL_AUTO_HOLD`(1024) 비트를 켬. 트레일블레이저·트랙스의 안전 비트는 3 → 1027. 트레일블레이저는 순정 카메라 0x2CB·0x370 기준이 200ms 넘게 끊기면 오토홀드를 풂. 페달을 놓은 뒤라면 기준이 돌아와도 다시 걸지 않음(계속 꾹 밟고 있으면 복구 즉시 다시 걸림) |
| `opendbc/safety/safety/safety_gm.h` | `gm_manual_hold`의 `gm_sdgm` 조건을 빼고 `!gm_skip_relay_check`(NO_CAMERA 아님)를 추가. 오토홀드가 준비·유지 중이면 0x2CB apply 요청으로 `controls_allowed`를 켜는 기존 경로(SDGM 아닌 차)를 막음 |
| `opendbc/car/gm/tests/test_manual_auto_hold.py` | 판다 시험을 SDGM(버스 2)·일반 카메라(버스 0) 두 모드로, 컨트롤러·인터페이스 끝단 시험을 세 차종으로 확장 |

브레이크 버스는 기존 코드가 이미 고른다. 트래버스는 카메라 버스(2), 트레일블레이저·트랙스는 파워트레인 버스(0)로 나가고,
판다 송신 허용 목록도 하네스별로 그 버스 하나만 연다. 트레일블레이저는 기존 롱컨 수정대로 순정 0x2CB 카운터에 맞춰 보낸다.
판다 예외 범위(정차·운전자 준비·입력 신선도·가스/리젠/크루즈 없음·0xA 모드·400 이하, `controls_allowed` 미부여)는 그대로다.

일반 카메라 롱컨(SDGM 아님)의 판다는 원래 0x2CB apply 송신만으로 `controls_allowed`를 켠다(당근 자동 인게이지용, 기존 동작).
오토홀드 중에는 이 경로를 막아, 늦게 오거나 잘못된 apply 요청이 가속·일반 제동 권한으로 바뀌지 않게 했다.
판다에서 오토홀드 준비·유지 상태가 풀린 뒤(가스, 차 움직임, 순정 크루즈 켜짐, 입력 끊김, SET/RES 버튼 인게이지)에는 기존 동작 그대로다.
가벼운 탭으로 화면의 홀드가 꺼져도 정차 중이면 판다는 아직 홀드로 보므로, 그때 인게이지는 SET/RES 버튼으로 한다(버튼은 바로 권한을 연다).

트레일블레이저는 순정 카메라 0x2CB 주기에 맞춰서만 0x315를 보낸다. 기준 메시지가 끊기면 브레이크 명령이 안 나가므로,
그 상태에서 AUTOHOLD를 표시하지 않도록 오토홀드를 푼다(Codex 리뷰 지적 반영).

## 근거 로그

- 트레일블레이저 `000000b6--9e4543502d`(fix_pls 59467c7f): 롱컨 켜짐, 안전 비트 3, 오토홀드 0회.
  필요한 입력 0x34A(5)·0xC9(8)·0x1C4(8)·0xBE(6)가 버스 0에 있고, 오픈파일럿 0x315는 버스 0으로 나감.
  정차 브레이크 원시값 중앙 61, 이 로그 최대 75(꾹 밟은 기록 없음).
- 트래버스 204~209: 정차 브레이크 중앙 44~63, 오토홀드 시작 순간 80~117. 두 차의 값 크기는 비슷하다.
- 트랙스 로그는 없다.

## 실차에서 확인할 것 (아직 안 함)

- 트래버스만 실차로 확인됐다. 트레일블레이저·트랙스의 EBCM이 ACC가 꺼진 상태에서 마찰 브레이크 요청을 실제로 따르는지는 모른다.
  트레일블레이저는 카운터가 어긋나면 크루즈 고장이 나던 차라, 첫 시험 전후로 고장 표시를 같이 본다.
- 첫 시험은 평지에서, 오른발을 브레이크 위에 둔 채로 한다. 화면에 AUTOHOLD가 떠도 차가 밀리면 바로 브레이크를 밟는다.
  차가 0.05 m/s 넘게 움직이면 오토홀드는 스스로 풀린다.
- 확인 순서: 꾹 밟아 정차 → AUTOHOLD 표시 → 발을 떼도 정지 유지 → 가볍게 톡 밟았다 떼면 해제 → 가속 페달로 출발.
- 경사에서 400으로 버티는지는 차마다 다르다. 주차 브레이크 대신 쓰지 않는다.

## 설치

fix_pls를 받은 뒤 재부팅하면 빌드되면서 판다 펌웨어도 새로 만들어지고, pandad가 서명이 다르면 자동으로 다시 쓴다.
판다 펌웨어가 바뀌므로 차가 꺼진(오프로드) 상태에서 업데이트한다.
